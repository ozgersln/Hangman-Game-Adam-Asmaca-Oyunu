# Hangman Game / Adam Asmaca Oyunu

## English Version

This project is a desktop-based Hangman game developed in C#.  
It allows the player to guess a hidden word letter by letter through a graphical user interface.

The game is designed with fundamental object-oriented programming principles and provides an interactive desktop experience.

### Features

- Desktop GUI application
- Word guessing game logic
- Real-time feedback for correct and incorrect guesses
- Game state control (win/lose condition)
- Clean and user-friendly interface

### Technologies Used

- C#
- .NET Framework / .NET
- Windows Forms

### How to Run

1. Open the project in Visual Studio.
2. Build the solution.
3. Run the application.
